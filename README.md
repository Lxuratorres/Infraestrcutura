# Ejercicio 1: Mi Primera Imagen Docker

Este repositorio contiene la solución al Ejercicio 1 de la competencia de Infraestructura TI. Se implementa una API básica en Flask contenerizada aplicando buenas prácticas de seguridad (usuario no-root) y optimización de caché.

## Instrucciones de Ejecución

1. Asegúrate de tener Docker y Docker Compose instalados en tu sistema.
2. Abre una terminal en la raíz de esta carpeta.
3. Ejecuta el siguiente comando para construir la imagen y levantar el contenedor en segundo plano:
   ```bash
   docker compose up -d
